## Даты результатов (`results_at`)

`results_at` задаёт, когда бот спросит «прошёл на следующий этап?». Без этого поля
бот спрашивает за 3 дня до следующего этапа, и только если тот подтверждён. У
школьных этапов ВсОШ муниципальный этап в основном `tentative`, поэтому вопрос не
отправлялся вовсе. Время ставится 20:00 по месту проведения, если источник не
называет другое.

- **ВсОШ:** 28 школьных этапов. Используются даты публикации предварительных
  результатов из [графика школьного этапа](https://vos.olimpiada.ru/2026/school),
  например 27.10 программирование, 29.10 экономика, 30.10 ИИ. Практическим турам
  по труду поле не ставилось: у них нет следующего этапа.
- **МОШ:** история искусств — 23.12 (проходной балл). Вероятность и статистика —
  8.12 (≤14 дней по регламенту). Информатика — 4.02 и 18.03 (списки приглашённых
  не позднее чем за 10 дней до финала).
- **Перечневые и другие:**

  | Олимпиада | Дата результатов |
  |---|---|
  | Ломоносов (информатика, право), Фемида | 30.12 — списки прошедших / допущенных |
  | Кутафинская | 30.01 |
  | СПбГУ | 25.12 20:00 (было 00:00) |
  | Всесибирская | 25.12 (НГУ, +07:00) |

  | Бельчонок | 18.01 (+07:00) |

  | Yandex Cup | 10.11 — финалисты |
  | Всероссийская по ИИ | 23.10 — основной этап |
